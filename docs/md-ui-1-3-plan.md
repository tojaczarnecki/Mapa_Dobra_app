# MD UI 1.3 — Nocleg i pełna mapa potrzeb

Kolejny etap po MD UI 1.2.

Priorytety:
1. Nie gubić publicznych kategorii na mapie — każda opublikowana placówka ze współrzędnymi ma pozostać widoczna.
2. Dodać brakujące kategorie mapy (wsparcie psychologiczne, odzież, inne) z bezpiecznym fallbackiem.
3. Przenieść szybki kreator „Nocleg na dzisiaj” na kompaktowy MD UI mobile-first bez zmiany logiki dopasowania.
4. Połączyć inteligentne wyszukiwanie noclegu z dedykowaną szybką ścieżką, zamiast udawać pewność dostępności zwykłą listą miejsc.
5. Zachować tri-state UNKNOWN i nie przedstawiać niepotwierdzonych danych jako spełnionych warunków.
