# Dobra Mapa - zaślepka startowa

Samodzielna statyczna zaślepka WWW przygotowana pod domenę `dobramapa.pl`. Strona pozostaje w nieskończonym stanie ładowania i wizualnie nawiązuje do loadera aplikacji.

## Wdrożenie

Wgraj na serwer zawartość katalogu `dobra-mapa-zapowiedz`, tak aby plik `index.html` był plikiem startowym domeny.

W paczce są:

- `index.html` - ekran loadera
- `styles.css` - wygląd, responsywność i animacja nieskończonego ładowania
- `script.js` - zapętlony licznik postępu
- `assets/` - logo, symbol, ikona i favicon
- `manifest.webmanifest` - metadane aplikacyjne
- `robots.txt` - podstawowa konfiguracja indeksowania
- `sitemap.xml` - mapa strony dla domeny `dobramapa.pl`
- `polityka-prywatnosci/` - informacja o prywatności

## Formularz i kontakt

Zaślepka nie zawiera formularza, CTA ani mechanizmu zapisu adresów e-mail. Nie wysyła żadnych danych.
